# VEIL — State-Driven Conversational Instrument Specification

## 1. Core Philosophy
VEIL is a state-driven, conversational software instrument. Rather than displaying forms or terminals, it reveals itself one decision at a time.

### Principles
- **One Decision at a Time**: The interface presents only the current prompt (e.g. "What would you like to do?", "Select the file to conceal", "Choose a carrier image", "Set an encryption passphrase").
- **Spatial Evolution**: Selected files and choices transform in-place into minimal visual objects. The workspace evolves smoothly via GSAP rather than stacking vertical forms.
- **Pure Black & White Metallurgy**: Obsidian foundation (`#060709`, `#0A0C0E`), off-white typography, hairline dividers (`rgba(255, 255, 255, 0.1)`), and zero decorative badges or terminal prompts.
- **Zero-Noise Precision**: No fake command prompts (`veil >`), no permanent command lists (`/hide`, `/extract`), no status bars, no green Matrix text, no fake hacker jargon.
